# Code of Conduct

## The Short Version

Be kind. Be constructive. Don't be a jerk.

## Expected Behaviour

- Respectful and helpful communication
- Constructive feedback on issues and PRs
- Crediting original authors when building on their work

## Unacceptable Behaviour

- Harassment, hate speech, or personal attacks
- Spamming issues or PRs
- Claiming others' work as your own

## Enforcement

This is a small personal project maintained by one person. If someone's
being disruptive I'll warn them and, if needed, remove them from the
discussion.
