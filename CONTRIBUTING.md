# Contributing to Midnight-Ash

Thanks for your interest in contributing! 💜

## How You Can Contribute

- **Bug reports** — Open an issue with steps to reproduce
- **Suggestions** — Open a feature request issue
- **Pull requests** — See below

## Branching & Forks

This is my personal theme built to my preferences, but that doesn't mean
you can't make it your own!

- **Forks are welcome** — Want a blue version? A green one? Fork it and go wild.
  Just credit the original authors listed in the README.
- **Branches** — Feel free to branch and experiment. PRs for personal preference
  changes (e.g. different accent colors) are unlikely to be merged into main,
  but a well-made blue variant as a separate branch or fork is totally valid.

## What PRs Are Likely to Be Accepted

✅ Bug fixes  
✅ Compatibility fixes for new Discord/client updates  
✅ Performance improvements  
✅ Documentation improvements  
✅ New opt-in CSS variables (that don't break defaults)  

## What PRs Are Unlikely to Be Merged

❌ Major visual/style changes that conflict with the purple aesthetic  
❌ Changes that break any supported client  
❌ Removing existing features without discussion  

> If you're unsure, open an issue first and ask!

## Code Style

- Follow the existing structure and formatting of `midnight-ash.css`
- Use `oklch()` color syntax (as of V6.0.0)
- Use modern `hsl()` slash syntax, not comma syntax
- Run Stylelint and Prettier before submitting if possible

## License Reminder

By contributing, you agree your changes will be licensed under GPL v3.0,
consistent with this project. Please don't submit code you don't have the
right to contribute.
