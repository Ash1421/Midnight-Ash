# ⚠️ Unsupported Features (Aliucord Port)

Aliucord's Themer plugin only exposes a fixed set of Android resource **colors**, a global/partial **font override**, and an optional **background image + overlay**. It cannot execute CSS, inject markup, or restyle layout. The following Midnight Ash features are therefore **not reproducible** in this port and are intentionally left out of `Midnight-Ash.json` rather than faked with an invented key:

| Feature | Source | Why it can't be ported |
|---|---|---|
| **Settings Modal redesign** | `SettingsModal.css` (DevilBro) | Restructures Discord's settings DOM into a modal window. Aliucord has no DOM/layout injection — it can only recolor existing native Android views. |
| **Horizontal Server List** | `HorizontalServerList.css` (Gibbu) | Changes flex-direction of the server list from column to row. This is a layout change, not a color; Aliucord has no equivalent layout hook. |
| **Radial Status** | `RadialStatus.css` (Gibbu) | Draws custom circular SVG/CSS status rings around avatars, replacing Discord's default status badge shape entirely. Aliucord can only tint the *existing* status drawables, not replace their geometry. |
| **Apple Emoji replacement** | `Apple.css` (DevilBro) | Swaps Discord's emoji font/spritesheet for Apple's emoji set via CSS asset replacement. Aliucord's `fonts` block can override text typefaces, but not the twemoji/emoji rendering pipeline. |
| **CSS animations & transitions** | `--animations`, `--list-item-transition`, `--dms-icon-svg-transition`, `--border-hover-transition`, etc. | Aliucord has no animation/transition system — colors are static resource overrides. |
| **Custom DMs icon (moon SVG)** | `--dms-icon-svg-url`, `--custom-dms-icon` | The Themer plugin itself can't swap a drawable's vector geometry — it can only tint existing drawables (see `drawable_tints`). **Workaround:** the separate [HomeIconSwitcher](https://github.com/nyakowint/AliuPlugins/tree/main/HomeIconSwitcher) plugin (from [nyakowint/AliuPlugins](https://github.com/nyakowint/AliuPlugins)) *can* replace the home/DMs icon with an arbitrary image URL. See the README's Installation section for how to point it at Midnight Ash's own moon icon. |
| **Custom background image / gradient** | `--background-image`, `--dms-background-color` (linear-gradient) | Aliucord's `background.url` supports a single static image (not a CSS gradient) and requires "Full Transparency" to be enabled by the user; Midnight Ash's default configuration has both `--background-image` and `--custom-dms-background` set to `off`, so this is left empty/disabled to match the theme's default appearance. |
| **Custom window controls** | `--custom-window-controls`, `--window-control-size` | Desktop-client-only window chrome (minimize/maximize/close styling). Aliucord runs on Android and has no window controls. |
| **Custom chatbar height/alignment** | `--custom-chatbar`, `--chatbar-height`, `--chatbar-padding` | Layout/sizing change, not a color. |
| **Top bar title/position tweaks** | `--top-bar-title-position`, `--subtle-top-bar-title`, `--top-bar-button-position` | Desktop-client top bar layout, not applicable to Aliucord's mobile UI, and not a color value. |
| **Settings width/height** | `--settingswidth`, `--settingsheight`, `--settingsbackground` | Only meaningful together with the (unsupported) Settings Modal redesign above. |
| **Blur / panel blur** | `--panel-blur`, `--blur-amount`, `--remove-bg-layer`, `--transparency-tweaks` | Aliucord's `background.blur_radius` only blurs the optional background *image*, not arbitrary UI panels, and only takes effect with Full Transparency enabled — which is off by default to match Midnight Ash's non-transparent look. |
| **Small user panel toggle** | `--small-user-panel` | A layout/sizing tweak to the bottom-left user panel, not a color. |
| **Font weight override** | `--font-weight: 400` | Aliucord's `fonts` block can replace the *typeface file* but has no separate "weight" override independent of the font file itself. |
| **Hypesquad house icons** | `ic_hypesquad_house1/2/3_32dp` | These are official Discord brand icons. Midnight Ash's CSS does not recolor them either, so they are deliberately left at Aliucord's defaults rather than reskinned. |

## Design notes / assumptions made during the color port

- **Alpha-composited overlays.** The CSS defines many surface states (hover, active, selected, borders) as translucent white/black layered *over* whatever is beneath them (e.g. `hsl(0deg 0% 100% / 6%)`). Aliucord's `drawable_tints` and `colors` are opaque-or-translucent solid fills, not live compositing layers, so where a key is used as a **solid** fill (e.g. `drawable_overlay_channels_selected_dark`) the translucent CSS color was pre-flattened against its typical backdrop (the channel list background) into an equivalent solid RGB value. Where the target key natively supports alpha (e.g. `mention_highlight`, `brand_500_alpha_20`), the alpha channel was preserved instead.
- **`brand_new_100`–`brand_new_900` scale.** Midnight Ash's CSS only defines 5 purple stops (`--purple-1` through `--purple-5`). Aliucord's brand scale expects up to 25 stops (100–900 in steps of 30–100). The 5 CSS stops were mapped exactly onto `brand_new_300/400/500/600/700`, and the remaining stops were generated by interpolating lightness and chroma in OKLCH space around those anchors, keeping the same 310° purple hue throughout.
- **Link colors.** `midnight-ash.css` does not override Discord's default link color. Since Aliucord's `link`/`link_500` keys are always visible somewhere in the UI, they were set to the theme's own blue accent scale (`--blue-2` / `--blue-3`) rather than left at Discord's default blurple, for visual consistency with the rest of the port. This is a deliberate design choice, not a 1:1 CSS translation.
- **Channel-type glyph icons** (`ic_channel_text`, `ic_channel_voice`, etc.) aren't recolored by the source CSS either, but were given a light semantic tint (muted grey / red for NSFW / accent for pinned) to avoid a jarring, unthemed icon set sitting inside an otherwise fully dark AMOLED UI. If you prefer Aliucord/Discord's stock icon colors here, simply delete these keys from `drawable_tints`.
