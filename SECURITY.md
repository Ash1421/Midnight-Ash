# Security Policy

## Supported Versions

Only the latest release of Midnight-Ash is actively maintained.

| Version | Supported |
|---------|-----------|
| Latest  | ✅        |
| Older   | ❌        |

## Reporting a Vulnerability

While Midnight-Ash is a CSS theme and has a limited attack surface, if you
discover a security concern (e.g. an imported URL pointing to a malicious
resource, or a script injection risk), please **do not open a public issue**.

Instead, report it privately via one of the following:

- 🔒 **GitHub:** Use the private vulnerability reporting tool under the
  [Security tab](../../security/advisories/new) → "Report a vulnerability"
- 💬 **Discord Server:** [Open a ticket](https://rb.ash1421.com/discord)
- 📧 **Email:** [Ash1421.Business@gmail.com](mailto:Ash1421.Business@gmail.com)
- 🌐 **Website:** [ash1421.com](https://ash1421.com)

> ⏳ I'm a solo maintainer — I won't always respond instantly, but I will
> get back to you and aim to patch confirmed issues in the next release.
> Thank you for reporting responsibly!
